# Fault Line
## What is it:
This is a text based, choice-making game totally written in C.
Its based on the setting of Cyberpunk Edgerunners, but I didn't just rip it off. Only the setting is the same, all the characters and the whole storyline is original and written by me.
I wont spoil it but do play coz your choices DO MATTER.
also: There are total of 5 Episodes that make up the whole story, Only three are written in the program so only up till that point is playable. But I did try to end Episode 3 at a VERY interesting point lol,
so just keep in mind that *Episode 4 and 5 will be coming soon.*
Happy playing 
## How to play?: 
- Download the repo as a zip and extract the contents in a folder.
- Just run the .exe file and play!
- enter the option number of the choices you are presented with and then press enter to send it.
- 's' to save, 'l' to load and 'q' to quit the game at any prompt.
